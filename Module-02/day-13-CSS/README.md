## 🛠️ Code Implementation & Structure
The document includes a complete, production-ready implementation of the .menu-card component. It features a modern CSS architecture utilizing CSS custom properties, global box-sizing resets, robust typography configurations, and advanced layout structures for the ingredient lists.

* Global Reset: Uses box-sizing: border-box to ensure uniform box-model calculations.
* CSS Variables: All colors (backgrounds, borders, accents, text states) are strictly mapped to var() functions.
* Pseudo-Class & Pseudo-Element: Employs :hover transitions for interactivity, ::before generation to dynamically prefix the price with "ETB ", and :nth-child(even) to automate the alternating zebra-striping layout of the list items.
